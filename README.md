# Mini Banking Application

## Description
A Java-based desktop banking system that allows users to perform basic banking operations like account creation, login authentication, balance enquiry, deposit, withdrawal, and secure fund transfer using MySQL database integration.

## Tech Stack
- Java (Swing GUI)
- JDBC
- MySQL
- OOP Concepts

## Features
- User Registration and Login
- Account Creation
- Balance Inquiry
- Deposit and Withdraw Money
- Secure Fund Transfer (Transaction Handling)
- Transaction Commit & Rollback
- GUI-based interface

## Project Structure
UI Layer → Service Layer → DAO Layer → Database

## How to Run
1. Import project in Eclipse/IntelliJ
2. Setup MySQL database
3. Configure JDBC connection
4. Run Main file
